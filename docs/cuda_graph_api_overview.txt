3) IMPLEMENTATION DEPENDENCIES (WHAT DEPENDS ON WHAT)
-----------------------------------------------------------------------
Dependency legend:
- "Requires" = should be implemented first for meaningful validation.

Foundational dependencies:
- Most graph APIs require: cudaGraphCreate + cudaGraphDestroy.
- Exec update APIs require: cudaGraphInstantiate or cudaGraphInstantiateWithFlags.
- Node-set/get APIs require corresponding node creation APIs first.

Detailed dependency map:
- Dependency-edge APIs
  Requires: graph creation
  APIs: AddDependencies/RemoveDependencies/GetEdges + v2 variants

- Graph/node query APIs
  Requires: at least one node creation API
  APIs: GetRootNodes, NodeGetDependencies, NodeGetDependentNodes, NodeGetType

- Child-graph APIs
  Requires: GraphCreate + AddChildGraphNode
  APIs: ChildGraphNodeGetGraph, ExecChildGraphNodeSetParams

- Kernel node param APIs
  Requires: AddKernelNode
  APIs: KernelNodeGet/SetParams, KernelNodeGet/SetAttribute,
        KernelNodeCopyAttributes, ExecKernelNodeSetParams

- Host node param APIs
  Requires: AddHostNode
  APIs: HostNodeGet/SetParams, ExecHostNodeSetParams

- Memcpy node param APIs
  Requires: AddMemcpyNode/AddMemcpyNode1D/(To|From)Symbol
  APIs: MemcpyNodeGet/SetParams, MemcpyNodeSetParams1D,
        MemcpyNodeSetParams(To|From)Symbol,
        ExecMemcpyNodeSetParams variants

- Memset node param APIs
  Requires: AddMemsetNode
  APIs: MemsetNodeGet/SetParams, ExecMemsetNodeSetParams

- Event node APIs
  Requires: AddEventRecordNode / AddEventWaitNode
  APIs: EventRecordNodeGet/SetEvent, EventWaitNodeGet/SetEvent,
        ExecEventRecordNodeSetEvent, ExecEventWaitNodeSetEvent

- External semaphore node APIs
  Requires: AddExternalSemaphores(Signal|Wait)Node
  APIs: ExternalSemaphores(Signal|Wait)NodeGet/SetParams,
        ExecExternalSemaphores(Signal|Wait)NodeSetParams

- Memory alloc/free node query APIs
  Requires: AddMemAllocNode / AddMemFreeNode
  APIs: MemAllocNodeGetParams, MemFreeNodeGetParams

- Generic node APIs
  Requires: AddNode/AddNode_v2
  APIs: NodeSetParams, ExecNodeSetParams

- Exec update APIs
  Requires: Instantiate + graph/node mutation path
  APIs: InstantiateWithParams, ExecUpdate, ExecGetFlags, NodeGetEnabled,
        NodeSetEnabled

- User object APIs
  Independent of node type but usually exercised with graph lifecycle
  APIs: UserObjectCreate/Retain/Release + GraphRetain/ReleaseUserObject

- Graph memory attribute APIs
  Independent of graph topology
  APIs: DeviceGetGraphMemAttribute, DeviceSetGraphMemAttribute,
        DeviceGraphMemTrim

5) PRIORITY SUGGESTION (IF YOU WANT FAST PRACTICAL COVERAGE)
-----------------------------------------------------------------------
Implement first:
- AddKernelNode, AddMemcpyNode(1D), AddMemsetNode, AddHostNode
- Kernel/Memcpy/Memset/Host node get/set params
- ExecKernel/Memcpy/Memset/HostNodeSetParams + ExecUpdate
- AddDependencies/RemoveDependencies/GetEdges/GetRootNodes

This combination unlocks most real-world graph capture/edit/replay workflows.
